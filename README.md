# DEGEN PLANET VIP — Backtest Replay (static web)

Open `site/index.html` (or host the `site/` folder on any static host). No build step, no backend.

- Data: `site/data.js` — 694 real OOS backtest trades (02 Nov 2025 → 13 Nov 2026, Monaco time (Europe/Monaco)), live system =
  HTF 4H/1H/30M (500k vol universe, cap 6/8/3) + Range variant "d". Source: /workspace/htf-strategy (reportr.py logic),
  regenerated by `export_data.py`. Sizing: $100,000 start, 1% risk ($1,000 loss at SL incl. fees), 0.06% taker both legs.
- Ticker: Bitunix snapshot (Bitunix public API has no CORS headers, so a browser can't fetch it live).
- URL params: `?join=https://t.me/...` sets the CTA link; `?screen=connect|dash|recap&at=0.6` jumps (for testing/screenshots).
- Deploy options: Cloudflare Pages (`npx wrangler pages deploy site --project-name degen-backtest`), Netlify Drop
  (drag the `site` folder to app.netlify.com/drop), or GitHub Pages (push `site/` to a repo, enable Pages).

- Times: all displayed clocks and trade timestamps use IANA `Europe/Monaco` (CET/CEST, auto DST), labeled “Monaco”. A live clock ticks every second in the header / boot screen. The equity-line date is the backtest replay cursor (also Monaco).
- Logo: official gold DP mark in the boot screen, header, favicon, PWA icons, and Open Graph image.
- Music: royalty-free Mixkit tracks (see `site/audio/CREDITS.txt`). Tap anywhere to start (browsers block autoplay); 🔊/🔇 toggle remembers on/off. Volume 0.4, playlist loops.
